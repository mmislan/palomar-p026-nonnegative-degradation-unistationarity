# Unistationarity of source-minimal Type II_l autocatalytic cores (l >= 3) and of Type V core normal forms under nonnegative degradation

Nandan, Nghe and Unterberger asked whether uniqueness of positive stationary states of diluted autocatalytic cores, known under positive degradation of every species, survives when some species are not degraded, leaving Type V and Type II_l with l > 2 open. For two explicit normal forms of these cores, the reversible mass-action system has at most one strictly positive stationary state whenever all forward and reverse rate constants are positive and every linear degradation constant is nonnegative, so any or all of them may vanish. The first family consists of Type II_l networks with l ≥ 3 cyclically ordered forks, nonempty gaps of nonfork species, positive integer main weights, coefficient-one back products and reversible unit return chains, satisfying the topological autocatalysis condition (Top) and source minimality: no proper chemostatted restriction of the weak-stem skeleton retains (Top), and no rotated return cycle is stoichiometrically autocatalytic. When l = 3 and all stems are coincident, the network is X_i ⇌ m_i X_{i+1} + X_{i+2} (indices mod 3, m_i ≥ 1). The second family consists of Type V networks with base species U_0, U_1, U_2 and reactions S_i ⇌ U_{i+1} + U_{i+2}, where each S_i is identified with U_i or joined to it by an arbitrary finite reversible unit chain. Uniqueness holds for the full state, including every internal chain species.
