# Unistationarity of Type II_l and Type V normal forms with nonnegative degradation

Nandan, Nghe and Unterberger ([arXiv:2507.15546](https://arxiv.org/abs/2507.15546), Theorem 5.2 and the following remark) left uniqueness with degradation unresolved for Type II_l cores with l > 2 and, when some degradation rates vanish, for Type V cores. For the source-minimal Type II_l normal forms with l ≥ 3 and the Type V normal forms, unistationarity is established for reversible mass-action kinetics with positive forward and reverse rate constants and arbitrary nonnegative linear degradation. Any two strictly positive stationary concentration vectors coincide, including all internal species of the reversible unit chains. The Type II_l class includes separated stems and the coincident three-fork case. The proof combines passive-chain elimination and a ratio argument for Type V with boundary Jacobian nonsingularity and an implicit-function argument for Type II_l.
